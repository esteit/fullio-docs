# 9. Возвраты

Fullio создаёт возврат только после его физического поступления на склад. Клиент
не заявляет ожидаемый возврат и не передаёт его предполагаемый состав или причину.

## 9.1. Методы

| Метод            | Назначение                              |
|------------------|-----------------------------------------|
| `return.list`    | Список фактически поступивших возвратов |
| `return.get`     | Карточка возврата и результат проверки  |
| `return.respond` | Передать решение по проверенным товарам |

## 9.2. Статусы

| Статус               | Значение                                              |
|----------------------|-------------------------------------------------------|
| `received`           | Возврат зарегистрирован после физического поступления |
| `checking`           | Fullio определяет состав и состояние товаров          |
| `waiting_for_client` | Проверка завершена, требуется решение клиента         |
| `problem`            | К возврату заведена активная проблема                 |
| `completed`          | Все товары обработаны в соответствии с решениями      |

При создании проблемы возврат переходит в `problem`. После её решения он
возвращается в `checking` или `waiting_for_client`, либо переходит в `completed`.

## 9.3. Объект `return`

| Поле                | Тип         | Описание                                                        |
|---------------------|-------------|-----------------------------------------------------------------|
| `id`                | integer     | ID Fullio                                                       |
| `return_number`     | string      | Номер, присвоенный Fullio                                       |
| `status`            | string      | Текущий статус                                                  |
| `order`             | object/null | Сопоставленный заказ: `id`, `external_order_id`, `order_number` |
| `lines`             | array       | Фактически обнаруженные строки `return_line`                    |
| `problems`          | array       | Связанные общие объекты `problem`                               |
| `files`             | array       | Общие фотографии и вложения возврата                            |
| `charges_summary`   | object      | Краткие начисления за обработку                                 |
| `timeline`          | array       | История статусов                                                |
| `available_actions` | array       | Доступные действия клиента                                      |
| `received_at`       | datetime    | Время физического поступления                                   |
| `updated_at`        | datetime    | Время последнего изменения                                      |

`order` равен `null`, если Fullio не смог сопоставить возврат с заказом. Причина
возврата не является обязательным полем и в текущий контракт не входит.

## 9.4. Объект `return_line`

Строки создаёт Fullio по фактическому содержимому возврата.

| Поле                | Тип         | Описание                                  |
|---------------------|-------------|-------------------------------------------|
| `id`                | integer     | ID строки                                 |
| `observed_barcode`  | string/null | Штрихкод на поступившем товаре            |
| `product`           | object/null | Сопоставленный товар: `id`, `sku`, `name` |
| `quantity`          | integer     | Фактически обнаруженное количество        |
| `condition`         | string      | Результат проверки состояния              |
| `comment`           | string/null | Комментарий сотрудника Fullio             |
| `photos`            | array       | Фотографии состояния товара               |
| `allowed_decisions` | array       | Допустимые решения клиента                |
| `decision`          | string/null | Принятое решение                          |

Если товар невозможно определить, `product` равен `null`, а
`observed_barcode` содержит считанный код, если он есть.

Состояния:

| Состояние    | Значение                                      |
|--------------|-----------------------------------------------|
| `good`       | Товар без выявленных дефектов                 |
| `damaged`    | Повреждён товар или его упаковка              |
| `incomplete` | Не хватает части содержимого или комплектации |
| `used`       | Обнаружены следы использования                |
| `unknown`    | Состояние пока невозможно определить          |

Решения:

| Решение           | Значение                                             |
|-------------------|------------------------------------------------------|
| `return_to_stock` | Вернуть товар в доступный остаток                    |
| `block`           | Оставить товар на складе в заблокированном состоянии |
| `write_off`       | Списать товар с остатка                              |
| `dispose`         | Утилизировать товар                                  |
| `return_to_owner` | Отправить товар компании-клиенту                     |

Состояние не выбирает решение автоматически. Fullio возвращает допустимые варианты
в `allowed_decisions` с учётом сопоставления товара и результата проверки.

## 9.5. `return.list`

Фильтры: `search`, `status[]`, `requires_client_action`, `order_id`, `product_id`,
`received_from`, `received_to`, `updated_since`.

Сортировка: `return_number`, `received_at`, `updated_at`.

Результат содержит `returns[]` и `pagination`.

## 9.6. `return.get`

```json
{
  "method": "return.get",
  "params": {
    "return": {
      "id": 2001
    }
  }
}
```

Результат: `result.return` с фактическим составом, состоянием товаров и доступными
решениями.

## 9.7. `return.respond`

Решение передаётся отдельно для каждой строки, требующей действия клиента.

```json
{
  "method": "return.respond",
  "params": {
    "return": {
      "id": 2001,
      "decisions": [
        {
          "line_id": 2101,
          "decision": "return_to_stock",
          "comment": "Вернуть в доступный остаток"
        }
      ]
    }
  }
}
```

Решение должно входить в `allowed_decisions` строки. Фактическое движение остатка
выполняет Fullio; метод возвращает обновлённый `result.return`.
