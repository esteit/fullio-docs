# 1. Общие правила: оставшиеся требования

Реализованные подключение, авторизация, JSON-RPC, коды объектов, patch, даты,
пагинация, действия и ошибки описаны на главной странице **API** личного кабинета
(`/company-{companyId}/api`). Их описание и прежние примеры удалены отсюда.
Этот файл содержит только предложения для будущих разделов и инфраструктуры.

## Аудит запросов

Сохранить `X-Request-Id`, JSON-RPC `id`, `X-External-User-Id`, метод, компанию,
ключ, результат и длительность. Необязательный `X-External-User-Id` предназначен
для аудита и не влияет на авторизацию. Секреты не должны попадать в журналы.
Полнота этих данных остаётся отдельной задачей от уже реализованного авторства
изменений от владельца компании с источником API.

## Деньги в будущих разделах

Объект `Money` содержит целое количество копеек и валюту, без float:

```json
{"amount": 8500000, "currency": "RUB"}
```

## Будущие расширения ошибок и ограничение частоты

Поддержка `error.data`, безопасная обработка неожиданных исключений в bundle
и лимиты запросов остаются незавершёнными требованиями. Следующие обозначения
сохранены для проектируемых разделов, это не новые поля текущего ответа.

В описаниях будущих методов используются названия ошибок из таблицы ниже; это обозначения в документации, а не отдельное поле ответа. Прикладным причинам не назначаются отдельные числовые коды. Для отказа авторизации используется `error.code: 0` и `error.message: Authentication failed`; неожиданная внутренняя ошибка использует стандартный код `-32603`.

| Ошибка                      | Значение                              |
|-----------------------------|---------------------------------------|
| `AUTHENTICATION_FAILED`     | Единый отказ авторизации: ключ отсутствует, неверен или отозван либо компания отключена |
| `VALIDATION_FAILED`         | Ошибка входных данных                 |
| `ENTITY_NOT_FOUND`          | Объект не найден в компании ключа     |
| `INVALID_STATUS_TRANSITION` | Действие запрещено в текущем статусе  |
| `DUPLICATE_BUSINESS_KEY`    | Бизнес-номер уже используется         |
| `FILE_NOT_READY`            | Файл ещё не загружен или не обработан |
| `RATE_LIMIT_EXCEEDED`       | Превышен лимит запросов               |
| `INTERNAL_ERROR`            | Неожиданная ошибка Fullio             |

При ошибках входных данных `error.data.field_errors` содержит список ошибок полей. Пример элемента списка:

```json
{
  "field": "inbound.lines[0].expected_quantity",
  "code": "POSITIVE_INTEGER_REQUIRED",
  "message": "Количество должно быть больше нуля"
}
```
